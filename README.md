# Mtresearch-PPT

用于研究生开题、组会和研究现状汇报的科研 PPT 技能。包含通用工作流、论文精读模板、按论点选图模板和 PPT 页序读取脚本。

## 下载

无需安装 Git，可在仓库首页点击 **Code → Download ZIP**。

也可以在终端输入：

```bash
git clone https://github.com/2677643117-del/Mt-research.git mtresearch-ppt
```

## 安装与使用

将文件夹放到本地技能目录，名称为 `mtresearch-ppt`，并确认 `SKILL.md` 直接位于该文件夹下。例如 `~/.codex/skills/mtresearch-ppt/`。重新加载技能后调用 `$mtresearch-ppt`，提供研究方向、听众、页数及自己的论文或 PPT，即可从对应阶段继续。
